# Bootloader EEPROM on a Raspberry Pi 5: upgrade a locked Pi, what you need

**You have a Raspberry Pi 5 whose [check](bootloader-eeprom-pi5-check.md) says
NOT DONE, and want to give it the fleet's bootloader and lock it again, with
the Pi in your hands.** (How far each step has been tried by us is listed under
[What has been run](bootloader-eeprom.md#what-has-been-run).)

```{image} bootloader-eeprom/kit.svg

:class: only-light
```

The six steps, one page each, in this order:
