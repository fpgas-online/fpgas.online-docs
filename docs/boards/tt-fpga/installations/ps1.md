# Tiny Tapeout FPGA boards at ps1

**No Tiny Tapeout FPGA board is installed at ps1 (probed 3 September 2026).** This page is for whoever looks
after the boards at ps1 (Pumping Station: One, Chicago). The site itself is on the [PS1 site
page](../../../sites/ps1.md).

Tiny Tapeout FPGA demo boards are allocated to PS1 and not yet installed. The source inventory carried four
identical rows for them — host, switch port, IP, RPi MAC and RP2350 serial all TBD, and no board page — so
none can be named here. Source: the deployment table in the board's page in fpgas.online-test-designs (probed
live 2026-09-03) and the board summary in its `site-ps1.md`.

An installation at ps1 is not yet written for ps1 and not yet run by us at ps1. The hardware would be the same
as at welland ([the building guide](../building/index.md)); the steps to bring a board up at a site are in the
[deployment checklist](https://github.com/fpgas-online/fpgas.online-test-designs/blob/main/docs/hardware/deployment-checklist.md)
of the test-designs repository (not verified by us).
